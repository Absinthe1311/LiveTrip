## 🎯 项目概述

### 项目简介

**LiveTrip** 是一个基于 AI + IoT 的智能旅行规划系统，为用户提供个性化的旅行规划服务。

### 核心功能

1. **AI智能助手**：基于智谱AI GLM-4的自然语言对话,支持"我想去北京玩三天"等自然表达
2. **AI智能规划**：基于自主研发的多因素评分引擎
3. **热门目的地**：10个热门城市展示（北京、上海、厦门、成都、杭州、西安、武汉、三亚、丽江），659+精选景点
4. **IoT实时数据**：景点拥挤度、天气等实时信息
5. **智能推荐**：景点、酒店、餐厅推荐，支持跳过
6. **行程管理**：拖拽排序、备选景点、分享导出
7. **行李打包**：预设物品分类，自定义添加，自动保存
8. **图片管理**：上传、审核、管理景点图片，支持Cloudinary云存储
9. **游记撰写**：Markdown编辑器撰写游记
10. **协同规划**：多人协同编辑行程，实时同步和沟通

### 技术栈

**前端**：React 18.3.1 + TypeScript 5.7.3 + Vite 6.0.7 + Tailwind CSS

**后端**：Node.js + Express 4.21.2 + Prisma 6.1.0 + SQLite

**AI服务**：智谱AI GLM-4 (自然语言理解与对话)

**地图服务**：高德地图 API

**图标库**：Lucide React 0.577.0

## 💾 数据库设计

### 核心表结构

#### 1. User（用户表）
```prisma
model User {
  id          String   @id @default(uuid())
  username    String   @unique
  email       String   @unique
  password    String
  role        String   @default("user")
  avatar      String?
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
}
```

#### 2. Spot（景点表）
```prisma
model Spot {
  id              String   @id @default(uuid())
  name            String
  city            String
  description     String?
  rating          Float    @default(0)
  price           Float    @default(0)
  openingHours    String?
  location        String?
  latitude        Float?
  longitude       Float?
  category        String?
  tags            String?
  isHot          Boolean  @default(false)
  coverImage     String?
  createdAt      DateTime @default(now())
  updatedAt      DateTime @updatedAt
}
```

#### 3. Itinerary（行程表）
```prisma
model Itinerary {
  id            String   @id @default(uuid())
  userId        String
  title         String
  startDate     DateTime
  endDate       DateTime
  budget        Float
  status        String   @default("planning")
  createdAt     DateTime @default(now())
  updatedAt     DateTime @updatedAt
  user          User     @relation(fields: [userId], references: [id])
  items         ItineraryItem[]
}
```

#### 4. ItineraryItem（行程项表）
```prisma
model ItineraryItem {
  id            String   @id @default(uuid())
  itineraryId   String
  day           Int
  order         Int
  spotId        String?
  spotName      String
  startTime     String?
  endTime       String?
  type          String   // attraction, restaurant, hotel
  itinerary     Itinerary @relation(fields: [itineraryId], references: [id])
  spot          Spot?    @relation(fields: [spotId], references: [id])
}
```

#### 5. PackingItem（打包物品表）
```prisma
model PackingItem {
  id            String   @id @default(uuid())
  itineraryId   String
  itemName      String
  category      String
  isPacked      Boolean  @default(false)
  isCustom      Boolean  @default(false)
  createdAt     DateTime @default(now())
  itinerary     Itinerary @relation(fields: [itineraryId], references: [id])
}
```

#### 6. SpotImage（景点图片表）
```prisma
model SpotImage {
  id            String   @id @default(uuid())
  spotId        String
  url           String
  source        String   // admin, user, cloudinary
  status        String   @default("pending") // pending, approved, rejected
  priority      Int      @default(0)
  isPrimary     Boolean  @default(false)
  uploadedBy    String?
  createdAt     DateTime @default(now())
  spot          Spot     @relation(fields: [spotId], references: [id])
}
```

## 🚀 部署说明

### 环境要求

- Node.js >= 18.0.0
- npm >= 9.0.0
- SQLite 3.x

### 后端部署

1. **安装依赖**
```bash
cd backend
npm install
```

2. **配置环境变量**
```bash
cp .env.example .env
# 编辑 .env 文件，填入真实配置
```

3. **初始化数据库**
```bash
npm run prisma:generate
npm run prisma:migrate
npm run prisma:seed
```

4. **启动服务**
```bash
npm run dev  # 开发环境
npm run build && npm start  # 生产环境
```

### 前端部署

1. **安装依赖**
```bash
cd frontend
npm install
```

2. **配置环境变量**
```bash
cp .env.example .env
# 编辑 .env 文件
```

3. **构建生产版本**
```bash
npm run build
```

4. **部署到静态服务器**
```bash
# 将 dist 目录部署到 Nginx、Apache 或 CDN
```

### Nginx配置示例

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端
    location / {
        root /path/to/LiveTrip/frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    # 后端API
    location /api {
        proxy_pass http://localhost:3003;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

## ❓ 常见问题

### Q1: 如何添加新的热门城市？

**A**:
1. 在 `backend/prisma/seed.ts` 中添加城市数据
2. 在 `frontend/src/data/popularDestinations.ts` 中添加前端展示数据
3. 运行 `npm run prisma:seed` 更新数据库

### Q2: 如何修改景点评分算法？

**A**:
修改 `backend/src/services/scoringEngine.ts` 中的评分逻辑

### Q3: 如何更换图片存储服务？

**A**:
1. 修改 `backend/src/services/cloudinaryService.ts`
2. 更新环境变量配置
3. 迁移现有图片数据

### Q4: 如何添加新的AI功能？

**A**:
1. 在 `backend/src/services/agentService.ts` 中添加新工具
2. 在 `backend/src/controllers/agentController.ts` 中添加新接口
3. 在前端调用新接口

### Q5: 如何优化行程生成速度？

**A**:
1. 优化评分算法
2. 减少数据库查询
3. 使用缓存
4. 并行处理
