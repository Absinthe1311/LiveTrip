## 🎨 视觉效果说明

### 玻璃拟态效果
- **卡片背景**: `bg-white/10 backdrop-blur-xl border border-white/20`
- **悬浮动画**: `hover:scale-[1.02] transition-transform duration-300`
- **阴影效果**: `shadow-2xl`

### 颜色系统
- **背景色**: 深色半透明 `bg-black/40`
- **主要文字**: 白色 `text-white`
- **次要文字**: 浅灰 `text-white/80`
- **强调色**: 红色（倒计时）、黄色（高亮日期）、绿色（下一站）

### 布局比例（响应式）
- **大屏 (1280px+)**: 左 20% | 中 55% | 右 25%
- **中屏 (1024px-1279px)**: 左 15% | 中 65% | 右 20%
- **小屏 (<1024px)**: 单列布局 + 抽屉式导航

## 📦 组件清单

### 左侧导航栏
1. **品牌区** - Logo + 折叠按钮
2. **主菜单** - 6个导航项
3. **社区菜单** - 1个导航项
4. **我的旅行** - 4个导航项
5. **用户卡片** - 头像 + 用户信息

### 中间核心区
1. **顶部工具栏** - 搜索框 + 通知 + 设置 + 用户头像
2. **Next Flight 卡片** - 倒计时提醒
3. **Overall Budget 卡片** - 预算统计（4个分类）
4. **Bangalore Weather 卡片** - 天气信息
5. **Total Travel 卡片** - 国家/城市统计
6. **Most Visited 地图** - 世界地图 + 标记

### 右侧边栏
1. **月历组件** - 2024年8月日历
2. **Upcoming Tour** - 即将出行列表（2个行程）

## 🔄 交互设计

### 导航交互
- 点击菜单项 → 高亮显示 + 跳转页面
- 折叠按钮 → 收起/展开侧边栏

### 卡片交互
- 悬停 → 缩放动画 (scale 1.02)
- 点击 → 根据卡片类型执行相应操作

### 搜索交互
- 输入关键词 → 实时搜索建议
- 回车/点击 → 跳转搜索结果页

### 地图交互
- 悬停标记 → 显示详细信息
- 点击标记 → 跳转到目的地详情页

### 日历交互
- 点击日期 → 查看当日行程
- 左右箭头 → 切换月份

## 📱 响应式策略

### 桌面端 (1280px+)
- 完整三列布局
- 所有功能可用

### 平板端 (768px-1279px)
- 左侧导航折叠为图标
- 右侧边栏宽度减小
- 保持核心功能

### 移动端 (<768px)
- 单列布局
- 左侧导航变为抽屉式
- 右侧边栏移至底部或隐藏

## ⚡ 性能优化

### 图片优化
- 背景图片懒加载
- 使用 WebP 格式
- 提供占位符

### 毛玻璃效果优化
- 使用 CSS 硬件加速
- 限制模糊层数
- 提供降级方案

### 组件优化
- React.memo 避免重渲染
- useMemo 缓存计算结果
- useCallback 缓存事件处理
