# 景点图片复制方案

## 问题说明

数据库中同时存在"北京"和"北京市"两个城市名称：
- "北京市"的景点都有图片
- "北京"的景点没有图片
- 热门目的地页面展示时，部分景点没有图片

## 解决方案

**只复制图片，不删除任何数据**

将"北京市"景点的图片复制到同名的"北京"景点，两个城市数据都保留。

## 执行步骤

### 1. 执行图片复制脚本

```bash
cd backend
npx ts-node copy-spot-images.ts
```

### 2. 验证结果

脚本会输出：
- 找到的"北京市"景点数量
- 找到的"北京"景点数量
- 成功复制的景点数量
- 跳过的景点数量（已有图片）
- 验证结果

### 3. 重启服务

```bash
npm run dev
```

## 脚本功能

`copy-spot-images.ts` 脚本会：

1. **查询景点**
   - 查询所有"北京市"景点（包含图片）
   - 查询所有"北京"景点

2. **匹配同名景点**
   - 根据景点名称匹配
   - 例如："故宫博物院"（北京市）→ "故宫博物院"（北京）

3. **复制图片**
   - 复制 `coverImage` 字段
   - 复制 `SpotImage` 表中的图片记录
   - 只复制状态为 `approved` 的图片

4. **跳过已有图片**
   - 如果"北京"景点已有图片，则跳过
   - 避免重复复制

## 安全保证

- ✅ **不删除任何数据**
- ✅ **不修改现有数据**
- ✅ **只添加图片数据**
- ✅ **可重复执行**（已有图片会跳过）

## 预期结果

执行后：
- "北京"景点的图片数量增加
- 热门目的地页面所有景点都有图片
- "北京市"和"北京"数据都保留

## 注意事项

1. **执行前无需备份**（只添加数据，不删除）
2. **可重复执行**（已有图片会跳过）
3. **执行后重启服务**（确保缓存刷新）

## 后续建议

为避免未来出现类似问题，建议：
1. 统一城市命名规范（使用"北京市"而非"北京"）
2. 在添加景点时，自动检查并复制同名景点图片
3. 定期检查并修复缺失图片的景点
