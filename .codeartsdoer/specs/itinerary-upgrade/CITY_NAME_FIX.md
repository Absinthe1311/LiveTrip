# 城市名称重复问题修复方案

## 问题描述

数据库中同时存在"北京"和"北京市"两个城市名称：
- "北京市"的景点都有图片
- "北京"的景点没有图片
- 热门目的地页面将"北京"和"北京市"作为同一个地区展示，导致出现无图片景点

## 解决方案

### 方案1：数据修复脚本 ✅

**文件**：`backend/fix-city-duplication.ts`

**功能**：
1. 将"北京市"景点的图片复制到同名的"北京"景点
2. 删除重复的"北京"景点（保留"北京市"）
3. 清理关联数据（SpotImage、SpotIoTData、Favorite、Review等）

**执行方式**：
```bash
cd backend
npx ts-node fix-city-duplication.ts
```

**优点**：
- 一次性修复数据库
- 彻底解决重复问题
- 保留有图片的"北京市"数据

**缺点**：
- 需要手动执行脚本
- 会删除数据（建议先备份）

---

### 方案2：城市名称标准化 ✅

**文件**：`backend/src/controllers/destinationController.ts`

**功能**：
1. 定义城市名称映射表
   ```typescript
   const CITY_NAME_MAP = {
     '北京': '北京市',
     '上海': '上海市',
     '厦门': '厦门市',
     '成都': '成都市',
     '杭州': '杭州市',
     '西安': '西安市',
   };
   ```

2. 标准化函数
   ```typescript
   function normalizeCityName(city: string): string {
     return CITY_NAME_MAP[city] || city;
   }
   ```

3. 在查询时自动标准化城市名称
   - `getCitySpots()` - 获取城市景点
   - `getCityAllSpots()` - 获取所有景点

4. 更新热门城市列表
   ```typescript
   const HOT_CITIES = [
     { name: '北京市', ... },
     { name: '上海市', ... },
     ...
   ];
   ```

**优点**：
- 无需修改数据库
- 自动处理城市名称差异
- 向后兼容

**缺点**：
- 数据库中仍存在重复数据
- 每次查询都需要标准化

---

## 推荐方案

**组合使用方案1和方案2**：

1. **先执行方案1**：修复数据库，删除重复数据
2. **再应用方案2**：防止未来出现类似问题

这样可以：
- 彻底清理数据库
- 防止未来再次出现重复
- 确保所有景点都有图片

## 注意事项

1. **数据备份**：执行修复脚本前，务必备份数据库

2. **关联数据**：删除景点时，会同时删除：
   - SpotImage（景点图片）
   - SpotIoTData（IoT数据）
   - Favorite（收藏）
   - Review（评论）
   - ItineraryItem（行程项）

3. **城市名称**：统一使用带"市"的名称：
   - 北京市、上海市、厦门市、成都市、杭州市、西安市

4. **向后兼容**：标准化函数会自动处理不带"市"的名称
