# Frontend 函数列表

本目录记录了frontend项目中各个模块的函数列表，用于重构和优化参考。

## 目录结构

```
frontend/
├── api/              # API客户端封装
├── services/         # 业务服务层
├── hooks/            # React Hooks
├── utils/            # 工具函数
├── components/       # UI组件
├── pages/            # 页面组件
├── store/            # 状态管理
├── types/            # 类型定义
├── lib/              # 第三方库封装
└── config/           # 配置文件
```

## 文档说明

- **api.md** - API客户端函数，包括所有后端API调用封装
- **services.md** - 业务服务层函数，包括AI服务、协同服务等
- **hooks.md** - 自定义React Hooks
- **utils.md** - 工具函数，包括认证、缓存、导出等
- **components.md** - UI组件分类说明
- **pages.md** - 页面路由组件
- **store.md** - Zustand状态管理
- **types.md** - TypeScript类型定义
